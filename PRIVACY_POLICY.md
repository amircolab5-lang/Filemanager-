## 1. Introduction
Welcome to **Ticno File Manager** ("we," "our," or "the App"). We are committed to protecting your privacy. This Privacy Policy explains our practices regarding data handling and privacy when you use our application.

**Core Privacy Promise:** Ticno File Manager is designed as a secure, local-first utility. Your files, documents, media, and private vault content remain 100% on your device. We **do not** collect, store, sell, upload, or transmit your personal files to external servers.

---

## 2. Permissions and How We Use Them

To provide file management, cleaning, and compression features, Ticno File Manager requests the following permissions:

### A. All Files Access (`MANAGE_EXTERNAL_STORAGE`)
- **Purpose:** Ticno File Manager's core functionality is to browse, organize, search, copy, move, rename, delete, compress (ZIP), and extract files across both internal device storage and removable SD card storage.
- **Data Handling:** All file processing occurs strictly on your device. No directory structure, file contents, or personal documents are ever uploaded or transmitted to any server.

### B. Internet Access & Network State (`INTERNET`, `ACCESS_NETWORK_STATE`)
- **Purpose:** Used solely to load advertisements provided by Google AdMob and to verify network connectivity when accessing external developer support links or checking for app updates.
- **Data Handling:** No personal files or personal identifiable information (PII) are shared over the internet by our application.

### C. Notifications (`POST_NOTIFICATIONS`)
- **Purpose:** On Android 13 (API 33) and higher, this permission allows the app to display background progress notifications for long-running operations (such as large file transfers, storage junk cleaning, or ZIP compression).

### D. Install Packages (`REQUEST_INSTALL_PACKAGES`)
- **Purpose:** Required only when you explicitly choose to install or update an APK file directly from your device storage or downloads.

## 5. Security of Your Data
We implement best practices to protect your data:
- **Local Vault (THide):** Files stored in THide are stored locally on your device with obfuscated file structures. They never leave your device.
- **Zero Remote Storage:** We do not own, maintain, or connect to remote storage servers for your files.
